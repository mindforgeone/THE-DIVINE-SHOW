# Путь

Мобильное React-приложение для измеримого пути на 30, 90 или 120 дней. Это не список наказаний: приложение собирает доказательства действий, показывает динамику тела, работы, смелости и личных решений, а завершённые марафоны сохраняет в истории.

## Пространства

- **Сегодня** — карта дней, до трёх действий дня, редактируемый Кодекс, показатели тела, победа дня и ситуации тревоги/смелости.
- **Шаги** — единый список действий с доской, повторениями, фактическим временем и деньгами, связями с целями, навыками и желаниями.
- **Курс** — векторы жизни, дерево профессиональных навыков с доказательствами, желания с условиями и рассчитываемый персонаж.
- **Статистика** — графики питания, расхода, веса и действий, прогноз достижения веса, события пути и только фактические паттерны.

Марафон стартует один раз после принятия шести обязательств. Данные сохраняются сразу локально и синхронизируются с Firebase. День можно сохранить как черновик, а после закрытия он блокируется. Полностью заполненный прошедший день закрывается автоматически по заслуженному результату. Каждые семь дней требуется недельный итог, а в последний день — финальная рефлексия.

## Роли

Роль определяется только по Firebase UID в `src/auth/roles.js`.

- `admin` получает все четыре пространства и полный набор данных;
- `user` попадает в отдельный экран участника и не видит административный трекер;
- данные каждого аккаунта изолированы правилами Firestore и Storage.

Имя, почта и подпись Google не дают административных прав.

## Данные Firebase

Основные документы владельца:

```text
users/{uid}/trackers/marathon-current-v11
users/{uid}/trackers/marathon-history-v1
users/{uid}/trackers/steps-v1
users/{uid}/trackers/life-v1
users/{uid}/marathons/{journeyId}
```

Изображения загружаются в Firebase Storage под `users/{uid}/...`; в Firestore хранится только URL. Доступ к пользовательским путям разрешён владельцу и администратору.

`src/marathon/accountStorage.js` содержит поколение миграции. При первом входе администратора после этой версии транзакция удаляет известные старые документы марафона, шагов и Курса, создаёт маркер поколения и показывает стартовый экран. Повторный вход с тем же поколением данные не сбрасывает. Другие аккаунты миграция не затрагивает.

После завершения марафона приложение сохраняет неизменяемую копию и сводку: срок, даты, статус, процент выполнения, цвета дней, очки, вес, шаги, действия и финальный итог. Из Зала пути можно открыть подробности и начать новый марафон.

## Ключевые модули

```text
src/App.jsx                         оболочка, экраны, день и статистика
src/auth/roles.js                  роли по UID
src/marathon/model.js              расчёты марафона, дня и прогноза
src/marathon/useMarathonStore.js   локальная и облачная синхронизация
src/steps/                         действия, доска и статистика
src/life/model.js                  Кодекс, векторы, навыки, желания, события
src/life/useLifeStore.js           синхронизация Курса
src/life/CourseModule.jsx          пространство «Курс»
src/life/LifePanels.jsx            Кодекс, события и паттерны
firestore.rules                    правила Firestore
storage.rules                      правила Storage
```

## Запуск и проверка

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

Сквозные браузерные проверки запускаются с работающим Vite-сервером:

```bash
node tests/browser.mjs
node tests/auth-browser.mjs
```

Они используют вымышленные аккаунты и подменённое облако, поэтому не меняют реальные данные. `tests/firestore-rules.mjs` проверяет владельца, администратора, чужой аккаунт и гостя через официальный Rules API.

## Публикация

Правила Firebase и сайт публикуются отдельно:

```bash
firebase deploy --only firestore:rules,storage --project divine-show-db
npm run build
```

Собранный каталог `dist` разворачивается в ветку `gh-pages`. Firebase Authentication должен разрешать домен `mindforgeone.github.io`; на GitHub Pages используется вход Google через всплывающее окно.
